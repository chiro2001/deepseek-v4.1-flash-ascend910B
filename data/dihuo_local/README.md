# 《地火》短切片专用问题（1024 token 口径）

配 `data/dihuo.txt`（刘慈欣《地火》全文，24,119 字）的 **1024 token 正文切片**使用。
四个问题都**只依赖切片内部信息**，任务类型分散，随请求轮换。

| 文件 | 任务类型 | 依赖 |
|---|---|---|
| `quote.txt` | 逐字摘录 | 摘本段内的句子 |
| `qa.txt` | 抽取式问答 | 问本段出现的人物与动作 |
| `continue.txt` | 续写 | 接着本段写（现代文，比文言文好接） |
| `extract.txt` | 词频统计 + 定位 | 统计本段用词 |
| `summarize.txt` | 概括 | 概括本段情节 |

**为什么换《地火》**：先前用《红楼梦》（文言文）时，续写类任务的投机解码接受长度只有
1.4–1.6、吞吐 45–50 tok/s —— 文言文本身高熵、草稿模型难命中。现代白话小说更接近
真实业务负载（客服/文档/新闻），接受率更 representative。

## 语料从哪来（**本仓库不附带原文**）

《地火》是刘慈欣的文学作品，**著作权不属于本项目的 Apache-2.0 许可范围**，
因此仓库**不分发原文**，只提供来源与校验和，由使用者自行获取：

* 来源：<https://github.com/VeejaLiu/ScienceFictionCollection/blob/master/001%20-%20%E5%88%98%E6%85%88%E6%AC%A3(Cixin%20Liu)/%5B2000-1%5D%E3%80%8A%E5%9C%B0%E7%81%AB%E3%80%8B.txt>
* 上游那套 MIT 许可只覆盖其**整理工作**，不覆盖作品本身；请自行判断你所在地区的合规使用方式。

一条命令拿到并校验（下载 → 校验 sha256 → 清洗 → 再校验）：

```bash
bash tools/fetch_corpus.sh          # 产出 data/dihuo.txt
bash tools/fetch_corpus.sh --check  # 只校验已有文件
```

| 阶段 | sha256 |
|---|---|
| 上游原文（70,389 B） | `9e810bc1686ce17162340791d8d89932a2f0ab1e8a654ef3c2f3ad646fca5ef5` |
| 清洗后 `data/dihuo.txt`（24,119 字） | `00aefd13430d4be45424db3c3f832b6c012d9c60c199518f45feed5d0a57e52b` |

任一步哈希不符脚本会**拒绝继续**（避免产生不可复现的性能数字）。
换用别的文本也可以 —— 只要它有足够长的现代中文散文，接受长度会随文本不同。
