## 口径与未验证声明

- 通过就是通过：以上 228 项全部为本机实测；缺什么写什么（上表 ⛔ 两项与 device 门明确未做）。
- `planner_source` 生成的 AscendC kernel 与 device bridge **未在本机编译**（需 DAV 工具链）；本线对其只做文本级生成与固定结构检查，不声明 device 产物正确性。
- 数值负例语义分层：严格 oracle 对非法 counts/dtype/shape 抛错；宽容实现（plan_frame/C++）对值域非法生成 `word[2]=1` 回退帧——与 `source_factory.planner_source` 模板逐句对应，两者均无"把非法输入合法化"的行为。
- BF16 对比工具保留 v5 的 ≤1 ULP 口径并通过自检；本线没有 device 输出，因此没有 ULP 实测值，不外推。
- 不回填旧 M1/capacity6 的收益，不做速度/performance 声明；正式 TP8 ≤20ms/step 目标相关结论均不在此线。
