4. 为什么 sync→async 在正式窗口收益（−29%）远大于 A/A 屏幕（−8.6%）

正式 API 负载（A≈2.94、86 轮/请求）里宿主是瓶颈；A/A 屏幕（A≈5.9、43 轮）宿主占比更低。 async 调度把 _prepare_inputs/bookkeeping 等宿主段与设备执行重叠，因此宿主占比越高收益越大。 结合设备侧事实：整轮设备忙时 ≥27.3ms（见第 5 节），当前 32.97 里宿主暴露已压到约 5–6ms。
