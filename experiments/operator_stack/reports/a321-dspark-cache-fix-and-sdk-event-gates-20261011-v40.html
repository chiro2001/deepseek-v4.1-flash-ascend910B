K5 实际几何与覆盖率

正式 profile 的 target 为 40 个 GMM1/GMM2，容量 M36/local48；draft 为 3 个，容量 M15/local16。 实际 SDK patch_speculative_config.py 会把 draft 的私有 HF/model_arch config 转为 checkpoint 原生的 128 专家/top3；target 保持 384/top6。不能把 main 的 top6 或 M1/capacity6 二进制推广给 draft。

6 个测量请求共 48 nominal round；仅 42 个完整接受且 6 个输入 route 齐备的轮次，与 8 rank 的实际 route SHA 逐项吻合。最后 6 轮尾部缺项已排除。 42 轮含 14 个唯一 route SHA，共 13440 个 layer×rank 投影。local R 中位4、均值4.5、最大19；active experts 中位3、均值2.7213、最大10。 精确命中已测获益 R1/R3/R6-e47 的仅 32/13440=0.238%，去重后 10/4480=0.223%。更广的 late-expert 模式没有性能证明。

这些是受限的实际 target route 投影，未覆盖未接受/未导出轮次、draft route 或 actual GMM prepack consumer。 完整原生 fallback 的 CPU 协议、坏 frame/counts 反例已通过；没有设备实现或角色 tiling 数值门。 当前候选整网优先级已降低。
