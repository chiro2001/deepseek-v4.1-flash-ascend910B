## 2. 【推断·强】机理：**亚文本级的数值污染**

**最可能**：G3 把那块 **fp16 scale 平面**写错/写偏（布局、对齐、写序、或与 dequant 读侧不一致）。

| 现象 | 解释 |
|---|---|
| 目标模型答题 **10/10** | **单 token 校验对微扰鲁棒** —— 一个 token 的 logits 稍微偏一点，argmax 仍然对 |
| **取回路径逐字相同** | 那是"两次同一条路径"的比对，微扰是**确定性的** ⇒ 两次都一样 |
| **draft 接受率崩** | draft 必须"**逐 token 猜中 target 会选什么**" ⇒ 微扰直接让猜中率塌 |
| `ms/step` **几乎不变**（28.008 vs 27.905） | 每步时间由固定开销主导；**draft 被拒不让步变快，只让"出 token"变慢** ⇒ `tok/s` 掉 |

⇒ ★ **这正是`logs/123`那条教训的第二个实例，而且这次是"目标模型都对、只有投机崩"** ——
比第一次（三档全崩）**更隐蔽**：如果只跑文本探针，**会得出"G3 没问题"的结论**。

## 6. 沉淀

1. ★★★ **"文本正确"不等于"行为不变"**：投机解码的接受率是一条**独立的、更灵敏的**判据 ——
   **它对亚文本级的数值污染敏感，而文本/argmax 不敏感**。凡动 attention / KV / scale 的改动，必须同时报。
2. ★★ **判据要"指向不同对象"**：本卷四条判据覆盖了**三层**（模型输出 / 路径确定性 / draft-target 一致性），
   **只测前两层会漏掉最灵敏的那层**。选判据时先问"**它测的是哪个对象**"。
3. ★ **"性能没变化"是最危险的读数**：它可能意味着"改动无效"，也可能意味着"**改动有害但被固定开销掩盖**"。
   唯一的区分办法是**同时看行为闸**（已进 `a2/AGENTS.md §5b.0`）。
