## 3. 沉淀：**相位感知**的对比工具 `a2/scripts/compare_arm_perf.py`

规则（写进工具，不靠人记）：
1. **先按相位分组**（`fill` / `replay1` / `replay2`），**不同相位之间不给结论**；
   相位名不重合时**直接拒绝**并打印原因（"这本身就是不能比的证据"）。
2. `bneck` 的 `d2h/hp/hash` **只能按 same steps 对齐**比；一侧缺该步就标"不比较"。
3. 逐指标给"变化 %"，并按**方向**判好坏（TTFT/wall/total 越低越好；tok/s 越高越好），
