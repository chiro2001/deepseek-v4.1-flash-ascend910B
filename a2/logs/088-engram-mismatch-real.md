## 2. 【推断·强】`absent=0` 但 `PAGELESS=8` —— 两个计数讲的是**两件事**

这两条同时成立，只能这样解释：

| 计数 | 含义 | 本臂 |
|---|---|---|
| `absent` | 真 token **拿到了**、但镜像里**整页缺失**（本会 `KeyError` 的那些槽位） | **0** ⇒ 修复把这类**全兜住了** |
| `mismatch` | 真 token **拿到了**、镜像里**有值但不同**（陈旧页） | **6** ⇒ **mode=1 不覆盖 ⇒ 仍是静默错** |
| `unavailable` | 真 token **拿不到**（`prev_tok=-1`：越界 / 超出已提交长度 / runner 未发布） | **1194** |
| `ENGRAM-PAGELESS` | kernel 走标量回退时**读到缺页** ⇒ 按 barrier 取 pad | **8** ⇒ 说明**仍有真 token 拿不到的缺页**，由 pad 兜底 |

⇒ ★ **两类残余**：
1. **能拿到真值但镜像陈旧**（`mismatch=6`）⇒ **可修**，升 `mode=2` 覆写即消；
2. **拿不到真值**（`unavailable=1194` ⇒ 其中一部分表现为 `PAGELESS=8`）⇒ **`mode=2` 也修不了**，
   因为这需要 `model_runner_v1` 真的发布了那些 token；属于**另一个洞**（要么修发布侧，要么承认 pad 兜底）。

★ 这与 `ENGRAM-OFFLOAD-EXACT-FIX.md §2` 提前列出的"残余静默点②（陈旧页）"**逐条对上**
——设计时是【推断】，现在是【实测】。
