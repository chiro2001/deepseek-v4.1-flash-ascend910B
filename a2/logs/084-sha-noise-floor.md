## 0. 一句话

`083 §2` 说"跨运行 sha 无效"是对的，但**不够精确** —— 精确的说法是：

> **聚合 sha 太粗**（16 个 prompt 里坏一个就整体不等），而**逐 prompt 比对有真实判别力**；
> 直接量出来的**噪声地板 = 2/16（≈12.5%）**。

⇒ 这条量化**当场改判了 `069 §2.6` 里的一句推断**（见 §3）。

## 1. 【实测】三个对照，逐 prompt 算

口径：`client.json` 的 `fill_out_sha256_by_prompt`（16 个 prompt 各自的输出 sha），
比较"两个**不同运行**之间逐 prompt 相同的条数"。★ 这是**跨运行**比对，正是 `083 §2` 怀疑的那类 ——
本节把它从"定性无效"变成"定量有地板"。

| # | A 臂 | B 臂 | 两者的差别 | 逐 prompt 相同 | 聚合 sha |
|---|---|---|---|---:|---|
| 1 | `p2e-engram1-dev0-dg1-offload` | `p2h-base075-rerun` | ★ **没有差别**（同配置、同 salt、同文件） | ★ **14/16** | 不等 |
| 2 | `p1b-tierB-dg1-offload` | `p2c-dg1-tinypool-noengram` | 池 **56 GiB vs 1 MiB**（差 3 个数量级；`hits` 901,120 vs 0） | ★ **16/16** | 相等 |
| 3 | `p1a-tierB-dg0-offload` | `p1b-tierB-dg1-offload` | **`DRAFT_GRAPH` 0 vs 1** | **14/16** | 不等 |

## 2. 判据怎么用（修订 `083 §2.2`）

| 场景 | 用什么 | 阈值 |
|---|---|---|
| **同一次运行内**比较（首选） | `replay1` vs `replay2`（`--rounds 3`，两轮都走池取回） | **要求 16/16 逐字相同**（同进程、同 salt ⇒ 没有跨运行噪声） |
| **跨运行**比较（次选） | `fill_out_sha256_by_prompt` **逐 prompt 数** | ★ **差 ≤2 个 prompt 不算证据**（地板）；**差 ≥3 个**才值得追 |
| 纯聚合 sha | `fill_out_sha256_all` | ⛔ **不要单独用**（16 个里坏 1 个就不等） |
| 语义层 | `text_correctness_probe.py --mode prefix-pair` | 第 2 发起逐字相同 |

★ 新增脚本 `a2/scripts/check_same_run_replay.py` 走的是**第一行**（同运行内），所以它不受地板影响 ——
这也解释了为什么"跨运行不可用"不等于"文本层判据不可用"。

## 3. ★★★ 据此**改判** `069 §2.6`

`069 §2.6` 原文有**两条**推断，现在分开看：

| 原文 | 判 | 为什么 |
|---|---|---|
| "**冷池（1 MiB，零命中）与热池（56 GiB，命中 901,120）给出逐字节相同的 fill 输出** ⇒ 独立佐证 `048 §2`" | ★ **保留（并升级）** | 逐 prompt **16/16 相同**，**高于噪声地板**（地板是 14/16）。加上 `hits` 差 3 个数量级，这条是本仓关于"池大小不影响输出"的**最强证据**。 |
| "两个 **DG0** 臂的 sha 与它们**不同**（`p1a = 8cd9c27b…`）⇒ 这条 sha **能区分「draft 入图 / draft eager」**" | ⛔ **不支持（改判）** | 逐 prompt 只有 **14/16 相同** —— **与"同配置两次运行"的地板一模一样**（也是 14/16）。⇒ **这个差异量无法与纯噪声区分**。要立这条，必须 **每组各跑 ≥3 次** 取分布，或改用**同运行内**判据。 |

⇒ 同时说明 `069 §2.5`（"稳态 A"）与**计数器类**判据**不受影响**（它们是确定性的引擎计数，不是输出抽样）。

★ `083 §2.3` 那条【未确认】**到此已答**：
`069 §2.3` 那张表**全是计数器**（`CPU_to_GPU` / `GPU_to_CPU` / `hits` / `BlockStored` / `BlockRemoved` /
宿主池 / `GPU KV cache size`）⇒ **跨运行可比，那条结论成立**；
受影响的只有 `§2.6` 里**含 sha 的那半句**（本条 §3 已改判）。
