## 4. 已收线的线与负结果

| 线 | 结论 |
|---|---|
| gmm1 kernel | **收线**：18.2 µs 硬地板；type=0 双重阻断（gmm2 缺内核 + 转换代价净亏 6–10×） |
| HcPre A1 | **不采纳**：内核在服务里**从未执行**（缓存未失效）；即便执行其效应 0.12–0.14 ms/step 也低于服务噪声底 ±0.16 |
| MoE 路由 | `MoeInitRoutingV3` **90% 是固定开销**（36 行被发射到 48 个 AIV 块、仅 1 核排序）；候选 A（降 BlockDim）是 2 行改动但**必须成对改** `SetBlockDim` + `set_coreNum` |
| `dispatch_ffn_combine` | **不能"只融合 dispatch+combine"**（签名要求两层专家权重）；且属 MC2 系（已实测中性偏负） |
| gate matmul + topk | **确认无法融合**（`moe_gating_top_k` 无权重入参） |
| wo_a 量化 | 精度不通过（单层 1.30–1.34% × 40 层） |
| CED-PD（③ 的 1.7×） | 需 **16 die**；12/14 die 结构性不可行 |
