## 1. 历史最优的三个 run（10-06，配置相同）

| run | BAT_TOKENS | KV 容量 | conc=1 p50 | p25 | n |
|---|---:|---:|---:|---:|---:|

三次一致性极高（极差 0.015 ms），说明这不是噪声。

### 1.1 同机同日受控对（10-06 08:16 vs 08:50）

| run | BAT_TOKENS | conc=1 p50 |
|---|---:|---:|
| `armrepackBat2048_1006_075016` | **2048** | **24.196** |
| `armIMG_restore8_1006_082849` | 8192 | **24.416** |

⇒ **−0.22 ms（−0.9%）**。方向与机制预测一致：
`_engram_max_tokens = max(BAT, capture_max)` ⇒ engram 缓冲
**8192 行（201 MB）→ 2048 行（50 MB）**，每步少一批填充/拷贝流量。
（`BAT-TOKENS-TRADEOFF-20261005` 已记录这个公式与两个尺寸。）

> ⚠️ 但 `KV32-SLOT-REPACK-A3-VERDICT` 的受控 A/B 判为"单流不变（+1.3% / −0.6%）"，
> 与这里的 −0.9% 在噪声量级内一致。**所以这 0.2~0.3 ms 只能说"方向为正、量级 ~1%"，不宜当确定收益。**
> 且它**有代价**：prefill 6.5K → 5.8K tok/s（−11%），首 token 更慢。

## 5. 复现

# 一次列出所有 TP8 单体 + SPEC=1 的 run，按 conc=1 档（hp<25.5）排序
ssh a3-21 'cd ~/cedpd-repo/results; python3 - <<PY
import re,glob,os,statistics as st
for d in sorted(glob.glob("*/")):
    r=d.rstrip("/"); f=os.path.join(r,"serve.log")
    if not os.path.isfile(f): continue
    t=open(f,errors="ignore").read()
    if "dspark" not in t.lower() or re.search(r"CED|V41_CED_ROLE", t): continue

    if len(c1)>=5:
        print("%-34s n=%-5d p25=%7.3f p50=%7.3f"%(r,len(c1),c1[len(c1)//4],st.median(c1)))
PY'
