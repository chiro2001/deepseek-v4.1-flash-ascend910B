# ★ A/B 判据的精度下限：本环境**测不出 <1% 的效应**（2026-10-07）

> 起因：`hc_pre_norm` 融合的 A/B 出现"融合 +1.44% / 空操作 +1.15% / 纯注释 +0.63%"三档，
> 而**同配置的两次基线**在两种比较口径下分别给出 +0.03% 与 −0.78%。
> 本文用 5 次起服的实测把**判据本身的精度**量出来。全部为【实测】。

---

## 0. 结论

| 项 | 值 |
|---|---|
| **run 内漂移**（同一次起服、300 样本块之间） | **0.5 ~ 0.7 ms（±1.4~2.8%）** |
| **run 间漂移**（同配置、两次独立起服） | **0.20 ms（−0.78%）**（全窗口径）/ **0.01 ms（+0.03%）**（全窗另一种算法） |
| ⇒ **可信判据下限** | **≈1%**；**小于 1% 的效应在本设置下不可判定** |
| 对目标 12% 的影响 | ✅ **无影响**（12% 远大于判据下限）；⚠️ 但**小优化（如 F2 的 0.6 ms = 2.4%）已接近下限** |

### 1.1 ★ A1 与 A2 是**同一份文件**，却差 0.78%

这是判据下限的直接证据：**同样配置、同样代码，两次起服的 p50 差 0.198 ms。**

（口径提醒：如果改用"全窗口"而非"尾部等长"，A1/A2 的差是 **+0.03%**。
⇒ **换口径就能让同一对基线从 +0.03% 变成 −0.78%**，进一步证明 <1% 的读数不可信。）

## 3. 因此要更正三处此前的表述

| 此前写的 | 更正为 |
|---|---|
| "融合 **+1.44%** 更慢"（`HCPRE-FUSE-E2E-NEGATIVE`） | **不可判定**。B 相对 A1 是 +0.77%，相对 A2 是 +1.6%，**跨基线就翻倍** |
| "A1 与 A2 完全复现（+0.03%）⇒ 漂移极小" | ❌ **错误**。那是**全窗口口径**的巧合；尾部等长口径下是 −0.78% |
| "融合自身贡献 ≈ +0.3%（噪声内）" | **无法分解出这一项**——低于判据下限 |
| **对 `hc_pre_norm` 的最终判决** | ✅ **仍是"不要投入"**（没有证据支持收益，而它需要重建镜像）；但**理由从"有害"改为"无可测收益"** |

## 4. 这份精度下限对后续所有实验的含义

### 4.1 必须遵守

1. **效应 <1% 的实验不要用单次起服 A/B 判决** —— 要么做**多次重复**（每次 10 min），要么放弃。
2. 报数字时**必须给出**：口径（尾部等长 or 全窗）、n、p10/p50/p90、**以及同配置基线的重复值**。
3. **A/B/A 设计**（基线→处理→基线复核）是底线，不是可选项。

### 4.2 对当前路线图的影响

| 候选 | 预期 | 能否判定 |
|---|---:|---|
| `HcPre` kernel 内部（78% 是开销） | **1.4~2.2 ms（5.5~8.7%）** | ✅ **可以** |
| F2 全族 | ≤0.62 ms（2.4%） | ⚠️ 接近下限，需 ≥2 次重复 |
| `hc_pre` 宿主路径 | 0.29 ms（1.15%） | ❌ **不可判定** |
| `hc_pre_norm` 融合 | ≤0.46 ms（宣称） | ❌ **不可判定** |
| 目标 −12%（2.95 ms） | — | ✅ 完全可以判定 |

⇒ **后续应优先做"预期 ≥2% 的项"**，把 <1% 的项降级为"顺带"。
