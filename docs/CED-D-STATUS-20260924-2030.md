## 关键实测结论（可直接引用）

- D 侧块**连续** ⇒ 1M 同请求 100% 正确；块**碎片/绕回** ⇒ 首 token 直接
  `id=1`(EOS)、logprob −2.10、`RB` 掉出 top-20。
- 失败相位与 KV 池容量吻合：1M 每请求约 7989 块 / 池 30082 ⇒ 第 3、7 次失败；
  900K 每请求约 6990 块 ⇒ 同样第 3、7 次；144K（1127 块）8/8 全过。
- P→D 的 `long_kv`/`index_k`/`index_scale` 在「通过-失败」配对间 maxdiff
  = 0/0/0 ⇒ **传输不是判别量**。
- 层 0 attention 输出在通过/失败间打印精度内一致；层 1 **输入**已分叉；层 2 的
  SMLA 选中集合改变 ⇒ 离散 top-k 是放大器。
- 噪声底：**通过-通过配对之间 digest 也不同**（max|Δattn_sum| ≈ 6~8，
  通过-失败 ≈ 114~115）。⇒ 判据必须看失败率，不能看逐位相等。
