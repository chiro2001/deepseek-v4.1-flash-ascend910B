# 第四轮总结（2026-10-04 晚）：一个错误结论的自我纠正 + 两个已交付内核优化

## 1. ★ 本轮最重要的事：撤回一个错误结论

我在第三轮末尾提出并在 `ABSORPTION-FINDING-20261004.md` 里写成"关键发现"的
**"算子级收益会被步内松弛吸收"** —— **是错的，本轮已撤回**（`CORRECTION-ABSORPTION-20261004.md`）。

**错因**：`armF_meta2` 那个 run **同时承载了 armF 部署验证与 metadata 的 sleep 剂量扫描**
（0/300/1000/5000/50000 µs 在同一实例内反复切换）⇒ `[bneck] hp` 样本混入 sleep>0 的分段。
**离散度是照妖镜**：armF 旧数据 p10–p90 高达 **120–286%**，而 stock 同级只有 7–16% ⇒
样本是双峰的，我用"配对差中位"跨过双峰得到了 +0.038 ms 的假值。

**修正**（新工具 `tools/ab_lines.py`：按行号取样本片段，marker=17252 之后重采）：

| n | stock | **armF（干净）** | Δ |
|---:|---:|---:|---:|
| 6 | 25.27 ms | 24.98 | **−0.28** |
| 12 | 28.18 | 27.78 | **−0.40** |
| 18 | 32.23 | 31.56 | −0.67 |
| 24 | 32.99 | 32.32 | −0.67 |
| 36 | 39.09 | 37.21 | **−1.87** |
| 42 | 40.56 | 38.79 | **−1.77** |

配对差中位 **−0.666 ms**，低离散档 **−1.086 ms**。

**同内核对照**（两个都是 stock 的 run 做漂移基线）：配对差中位 **−0.029 ms**、
低离散 **−0.082 ms** ⇒ armF 效应是漂移的 **13–23 倍**，且与算子级预测
（−7.56 µs/op × 40–43 = **−0.30~−0.33 ms/step**）**吻合**。

**修正后的模型**：**步时 ≈ 关键 stream 上的串行工作量；在该 stream 上减少工作量会 1:1 兑现。**
（不再有"会被吸收"的免责条款。）

## 2. 三条方法学教训（本轮代价换来的）

1. **不要把互相干扰的实验放进同一个服务实例的日志里**，尤其当判据来自该日志时。
   本轮把"Kernel A/B"与"sleep 剂量扫描"混在一个 run，直接产出一个错误的核心结论。
2. **判据前先看离散度**：p10–p90 相对值 >20% 就说明样本混了分布，中位数不可信。
3. **必须做同内核对照**（两个同配置 run 之间的漂移基线）才能声称"某改动有/无效果"。
   —— 本轮正是它把错误结论翻了回来，也应当成为此后所有 A/B 的**标准前置**。
