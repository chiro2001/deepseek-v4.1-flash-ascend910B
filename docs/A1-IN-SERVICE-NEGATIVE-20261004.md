# HcPre A1 在服务里**无效**（负结果，2026-10-04 晚）

> 子代理在 **die5 隔离环境**测到 A1（自适应 K_L0 128/64/32）在 M=6 图模式下
> **−2.61 µs/op**（配对中位，n=3），预期折算 **−0.21 ms/step（80 次/步）**。
> 本文件记录它在**真实服务**里的实测结果：**算子级无效**。

## 1. 服务内实测（同一实例前后两份 profile，同形状）

`HcPre` 的主要形状是 `"6,4,5120;24,20480;3;24;6,4"`（= decode M=6），
两实例对该形状的 `Task Duration` 中位：

| 指标 | stock（`armF_meta2`） | **A1（`armF_A1`）** | Δ |
|---|---:|---:|---:|
| `Task Duration` | **30.92 µs** | **31.18 µs** | **+0.26**（略差） |
| `aicore_time` | 16.78 | 17.70 | +0.92 |
| `aic_scalar_time` | 4.66 | 4.82 | +0.16 |
| `aiv_time` | 23.13 | 23.11 | −0.02 |
| `aiv_scalar_time` | 4.10 | 4.80 | +0.70 |

**A1 的档位确实被选中**（M=6 → `CeilAlign(6,16)=16 ≤ 64` → `kL0Size_=128`，即 A1 的快档），
`.o` md5 也确认在容器里（`de790a50`）—— **但时长没有变快，甚至略慢**。

## 2. 端到端同样没收益（且可能略负）

同一个 N 档扫描（N=1,2,4,8 × 6 rep），按行号隔离干净样本后配对：

| 对比 | 配对差中位 | 低离散档中位 |
|---|---:|---:|
| **armF+A1 vs armF 单独** | **+0.514 ms** | **+0.270 ms** |
| armF+A1 vs stock | −0.091 ms | −0.048 ms |
| （参考）armF 单独 vs stock | **−0.666 ms** | **−1.086 ms** |
| （参考）同内核对照漂移 | −0.029 ms | −0.082 ms |

⇒ **加入 A1 后，收益从 −0.67 ms 掉到 −0.09 ms**。其中约 0.02 ms 可由算子级的 +0.26 µs×80 解释，
其余更可能是跨实例漂移（本例的两次运行相隔一次完整重启）。

## 3. 结论与动作

* **不采纳 A1**：它在服务里没有可测收益（算子级 +0.26 µs、端到端不给正贡献），
  而交付多背一个非 stock 内核就是多一份风险。
* **已回退**：最终交付实例用 **armF only**（HcPre 的 `.o` md5 已回到 stock `5aa7b15c`）。
* **A1 的数值安全仍然成立**（514/514 eager + 16/16 图内逐元素零），
  所以这是"**正确但无用**"，不是"有害"。

## 4. 为什么隔离环境的 −2.61 µs 在服务里没出现（候选，未确证）

1. **周围上下文不同**：隔离 bench 里 HcPre 独占 die5，AIC/AIV 没有被别的 kernel 挤占；
   服务里它在 stream 146 上与 40 层的其它算子背靠背，**K_L0=128 带来的 L0 压力可能被掩盖**。
2. **测量基准不同**：子代理用 msprof `kernel_details.csv`；本文件用 `op_summary` 的 `Task Duration`
   （两者都应是设备侧，但取样与聚合口径不同）。
3. **M 的实际取值不同**：服务里还出现 `"5,4,5120"`（M=5）与 `"256,4,5120"`（M=256）两个形状；
   前者同样落 128 档，后者落 32 档 —— 但主要耗时在 M=6。
4. **真实差异可能只有 ±0.3 µs**：子代理的 −2.61 µs 是 n=3 的配对中位，
   而本文件的 +0.26 µs 是 26880 vs 15280 个样本的中位 —— **样本量差 3 个数量级**，
   更可能是子代理那侧受 die5 状态影响（他们自己记录过 ±6% 的 run-to-run 漂移）。

## 5. 方法学（第 3 条，与本轮别的教训并列）

**隔离环境（单算子、独占 die）的收益，必须回到真实服务里复核。**
本轮有**两个**这类案例：
* HcPre A1：隔离 −2.61 µs，服务 **+0.26 µs（无效）**；
* gmm1 armD：隔离 −3.5 µs，服务 **−0.66 µs（约 1/5 兑现，但方向对）**；
* gmm1 armF：隔离 −12.21 µs，服务 **−7.56 µs（约 62% 兑现）**。

⇒ **"隔离收益 → 服务收益"的兑现率在 0%–75% 之间波动，必须逐个实测，不能外推。**
